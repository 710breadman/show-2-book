# show-2-book

Tooling and project docs for turning a show or movie into a picture-book workflow.

## What is here

- `tools/` - Python scripts for indexing, analysis, frame selection, book building, QA, and rendering
- `project/` - the operating brief, standards, manifests, and reference indexes

## What is not here

- generated books
- raw input media
- temp renders and audit artifacts

## Core entry points

- `project/PIPELINE_README.md`
- `project/MASTER_BRIEF.md`
- `project/EDITORIAL_AND_DESIGN_STANDARD.md`
- `tools/build_picture_book.py`
- `tools/build_episode_storybook.py`
