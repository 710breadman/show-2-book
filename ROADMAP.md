# Autonomous v2 roadmap

The roadmap is dependency-driven, not date-driven. Every sprint runs in a fresh context and leaves a verified handoff.

## M0 — Safe autonomous foundation (S000–S009)

- Repository hygiene and private/public boundaries
- Windows/uv bootstrap
- Validated configuration and schemas
- Atomic sprint state and exact 62,768-token context packing
- Failure ledger, resumable stage graph, CLI, SQLite/FTS5, tests and CI

## M1 — Complete source understanding (S010–S019)

- ffprobe media identity
- Subtitle extraction and faster-whisper fallback
- Scene detection and frame index
- Cited research provider/cache
- Reception classification
- Exact quote archive
- Exhaustive JSON/Markdown master dossier

## M2 — Specialist editorial crew (S020–S024)

- Structured Ollama client with one cross-process request at a time
- Story Cartographer, Screen-to-Page Adapter, Picture-Book Editor
- Developmental & Emotional Reader and Cultural/Context Reader
- Independent review board and adversarial red team
- Final editor with scoped, reversible preference learning

## M3 — High-quality book generation (S025–S029)

- Adaptive-length recommended blueprint and optional cuts
- Ranked source-frame candidates
- Restrained layout system based on approved books
- PDF, print PDF, page images, editable package, dossier archive
- Problem-only QA and marked draft/final approval states

## M4 — Simple guided desktop workflow (S030–S034)

- Five-stage NiceGUI interface
- Page-plan, key-quote and frame review
- Non-blocking single/season queues
- Edition, override and preference management
- Fresh-context headless autonomous runner

## M5 — Benchmark-proven Windows release (S035–S038)

- Local-only approved-book benchmark registration
- Regression scoring without storing copyrighted pages
- Windows desktop/portable packaging
- SBOM, threat model, recovery docs and reproducible release

## v1 definition

A user can add one local video, receive a cited dossier and recommended book plan, review only key quotes/page choices, export a polished PDF, and see a concise problem report. The same installation can queue multiple episodes, survive restarts, preserve overrides, and continue around non-dependent blockers.
